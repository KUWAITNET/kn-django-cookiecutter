Rendered only when TURNSTILE_SITE_KEY is set. With no key the protection degrades to the honeypot field alone, so development, CI and UAT are never blocked by a missing secret - but a production deploy without a key is a go-live finding, and apps.core.checks reports it. The api.js loader is a third-party script and is therefore deferred; it is also the only third-party host in script-src besides the analytics domain. Server-side verification is not optional: the token this widget produces means nothing until apps.core.spam has POSTed it to the siteverify endpoint.
