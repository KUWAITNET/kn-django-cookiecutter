LANGUAGES_AVAILABLE entries are {code, name, name_local, bidi, url, is_current}. "url" is the ABSOLUTE url of THIS page in that language, resolved under that language so it carries the translated slug - never an /en/ -> /ar/ prefix swap, which 404s the moment a slug is translated. It is empty when the page does not exist in that language, and that language then gets no alternate: a hreflang pointing at a 404 is worse than no hreflang at all. {% endcomment %} {% comment %} Two things about the fallback chains below, both of which are load-bearing: * They use firstof, not the default filter.
